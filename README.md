# twitter-airline-sentiment

## 1. Project Overview
This project builds an end-to-end sentiment analysis pipeline for airline Twitter data. Classical machine learning models (Logistic Regression, Linear SVM, Naive Bayes, Random Forest, and XGBoost) are compared using CountVectorizer and TF-IDF features. The project then fine-tunes a BERT model using Hugging Face Transformers and deploys it as a REST API with FastAPI, Docker, and AWS EC2.
